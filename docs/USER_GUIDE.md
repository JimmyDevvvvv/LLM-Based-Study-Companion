# User Guide: Study Assistant

## Overview

The Study Assistant is a conversational interface that understands natural language and routes your requests to the appropriate tool automatically.

## Getting Started

1. Navigate to the **"Study Assistant"** tab
2. Type your request in natural language
3. Click the send button or press Enter
4. Wait for the AI to process and generate results

## Example Queries

### 📝 Quizzes

- "Create a 10-question quiz on photosynthesis"
- "Generate 5 multiple choice questions about Python loops"
- "Make a quiz on World War II"

### 🎴 Flashcards

- "Create flashcards for Chapter 3 vocabulary"
- "Make flashcards from this text about cell biology"
- "Generate flashcards for Spanish verbs"

### 📚 Study Guides

- "Summarize the French Revolution"
- "Create a study guide on quantum physics"
- "Generate lecture notes on machine learning"

### 💡 Explanations

- "Explain Newton's laws in simple terms"
- "What is photosynthesis?"
- "How does the water cycle work?"

### 💼 Project Ideas

- "Give me project ideas for data structures"
- "Suggest lab activities for chemistry"
- "Generate assignment ideas for Python course"

## How It Works

1. **You type a query** in natural language
2. **AI analyzes** your request to determine intent
3. **System routes** to the appropriate tool
4. **Results are generated** and displayed

## Clarification

If your query is ambiguous, the system will ask for clarification:

1. You'll see a dialog with tool options
2. Click the tool you want to use
3. The system will process your request with that tool

## Tips for Best Results

1. **Be specific**: "Create a quiz on photosynthesis" is better than "quiz"
2. **Include details**: Mention difficulty level, number of questions, etc.
3. **Use keywords**: Words like "quiz", "flashcard", "explain" help
4. **Ask naturally**: Write as you would ask a colleague

## Understanding Results

Each result shows:
- **Tool Used**: Which tool generated the result
- **Confidence**: How confident the AI was (0-100%)
- **Processing Time**: How long it took to generate

## Error Handling

If something goes wrong:
- Check your internet connection
- Try rephrasing your query
- Use the help button for examples
- Contact support if issues persist

## Keyboard Shortcuts

- **Enter**: Send query
- **Shift + Enter**: New line in query

## Help & Examples

Click the **Help** button (?) to see:
- Example queries by category
- Click any example to use it
- Learn about different tool types

## Switching Tools

You can still use individual tool tabs:
- **Chat**: General conversation
- **Content Generation**: Create lectures
- **Grading & Feedback**: Grade assignments
- **Quiz Generator**: Create quizzes
- **Admin Tools**: Generate templates
- **Project Ideas**: Get project suggestions
- **Help**: Get help about the tool

The Study Assistant provides a unified interface, but individual tools are still available for direct access.
